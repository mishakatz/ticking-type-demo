# Ticking Type

Одностраничное демо аналоговых часов. На весь экран — один квадратный
циферблат с тремя стрелками, показывающими реальное локальное время.
Клик в любом месте экрана листает коллекцию циферблатов по кругу.

Без фреймворков, без сборки, без зависимостей: один `index.html`, один
`style.css`, один `clock.js` и манифест `dials.json`. Циферблаты — растровые
картинки (`<img>`), стрелки и колпачок — inline SVG поверх, вращение через
CSS `transform: rotate()`, тени через `filter: drop-shadow()`.

## Запуск локально

Только через локальный HTTP-сервер. Не открывать `index.html` по `file://`:
при `file://` падает `fetch('dials.json')`, а чтение пикселей циферблата для
вычисления фона (canvas `getImageData`) бросает security-ошибку, потому что
изображение считается cross-origin и canvas «портится». По HTTP с того же
origin всё работает без атрибутов `crossorigin`.

```
python -m http.server 8000
# или
npx serve
```

Затем открыть `http://localhost:8000/`.

## Как добавить циферблат

1. Положить файл в `assets/dials/` — PNG, JPEG или WebP. Форматы могут лежать
   вперемешку. PNG — для прозрачности и чистой типографики, WebP — когда нужна
   и прозрачность, и меньший вес, JPEG — только для тяжёлых фото без прозрачности.
   Желательно, чтобы по краю циферблата был ровный читаемый фоновый тон без
   графики до самого обреза — из него вычисляется фон страницы.
2. Дописать имя файла в массив `dials` в `dials.json`. Порядок в массиве =
   порядок листания.

Элемент массива принимается в двух формах:

```json
{
  "dials": [
    "dial-01.png",
    { "file": "dial-02.png", "hands": "steel-light" }
  ]
}
```

Строка — путь к файлу. Объект — `{ "file": ..., "hands": ... }`, где `hands`
необязателен. В текущей версии `hands` нигде не читается; объектная форма
заложена под будущую привязку варианта/цвета стрелок к отдельному циферблату.

## Структура проекта

```
index.html        разметка, пять слоёв сцены
style.css         сцена, слои, тени, fade-in, адаптив
clock.js          движок: время, листание, фон, загрузка
dials.json        манифест: список и порядок циферблатов
.nojekyll         отключает обработку Jekyll на GitHub Pages
assets/
  hands/          стрелки и колпачок (inline SVG)
    hour.svg minute.svg second.svg cap.svg
  dials/          циферблаты (растр)
    dial-01.png ...
scripts/
  make_placeholders.py   генератор временных циферблатов-заглушек
```

## Плейсхолдеры

Циферблаты `dial-01..03.png` и четыре SVG-стрелки в `assets/hands/` —
**временные заглушки** для проверки механики (тик, листание, фон, fade-in,
адаптив). Заменяются финальными ассетами владельца без изменений в логике:

- Стрелки — по соглашению: квадратный `viewBox` (например `0 0 2048 2048`),
  остриё строго вверх (положение 12 часов), точка вращения — геометрический
  центр `viewBox`, чистый `path`, заливка управляемая (`fill="currentColor"`).
- Циферблаты — квадрат, ось часов в геометрическом центре, «12» строго вверху,
  рекомендуемый экспорт 2048 × 2048 px.

Цвет стрелок задаётся одной CSS-переменной `--hand-color` в `style.css`.

Сгенерировать заглушки заново: `python scripts/make_placeholders.py`
(нужен `pip install Pillow`).

## Deploy (GitHub Pages)

Статика, без сборки. Project site отдаётся из подпапки
`https://<аккаунт>.github.io/<репозиторий>/`, **поэтому все пути относительные**
(`./style.css`, `./clock.js`, `./dials.json`, `./assets/...`, и пути циферблатов
внутри `dials.json`). Никаких ведущих слэшей — абсолютный путь от корня домена
сломается онлайн, хотя локально по HTTP работал. Это самый частый провал
деплоя на Pages.

Шаги:

1. Запушить репозиторий на GitHub.
2. Settings → Pages → Source: **Deploy from a branch**, без GitHub Actions.
3. Branch: дефолтная ветка (или временно `feat/ticking-type-clock-demo`, чтобы
   показать коллегам до мержа), папка-источник — корень (`/`).
4. В корне лежит пустой `.nojekyll` — Pages раздаёт файлы как есть.

После пуша/мержа публикация занимает до минуты, Pages кэширует — иногда нужна
перезагрузка с очисткой кэша. Same-origin на Pages, поэтому `fetch` и чтение
пикселей через canvas работают без `crossorigin`, как на локальном HTTP.
